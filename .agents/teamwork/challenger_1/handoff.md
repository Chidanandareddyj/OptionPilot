## Challenges

### [Low] Challenge 1: State desynchronization between `showBoard` and history restoration
- **Assumption challenged**: Can a user restore a history snapshot while `showBoard` is active without exiting the board?
- **Attack scenario**: Open history drawer while looking at Live Market (`showBoard === true`), click snapshot.
- **Empirical test**: Verified in `app/dashboard/adversarial.test.ts` subtest 1. The handler explicitly invokes `setShowBoard(false)` along with `setActive(item)` and `setHistoryOpen(false)`.
- **Verdict**: PASS.

### [Low] Challenge 2: Runtime Null Reference in Compare Views Mode
- **Assumption challenged**: Can switching between compare mode and single mode trigger null pointer dereferences if `decision` in database is legacy single-view JSON?
- **Attack scenario**: Load analysis created in single-view mode, toggle `compareMode: true`, trigger re-score on left pane only.
- **Empirical test**: Verified in `app/dashboard/adversarial.test.ts` subtests 2, 4, and 5. `mergeCompareDecision` seeds the opposite pane from legacy single decision; `asDecision` validates schema; empty pane renders fallback hint cleanly.
- **Verdict**: PASS.

### [Low] Challenge 3: Responsive Overflow on Small Mobile Devices (360px)
- **Assumption challenged**: Do table cells, sticky header items, or slide-out sheets cause horizontal body scrolling on small screens?
- **Attack scenario**: Viewport set to 360px width.
- **Empirical test**: Inspected CSS container classes and tested layout tokens. Table is wrapped in `-mx-4 overflow-x-auto sm:mx-0`, header brand text is hidden via `max-[380px]:hidden` (leaving only the logo mark), drawer uses `w-full max-w-md`, and sub-bar uses `flex-wrap`.
- **Verdict**: PASS.
